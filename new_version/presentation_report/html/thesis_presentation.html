Pre-CPCV
CUSUM Filter & Triple Barrier Labeling
CUSUM Filter (AFML Ch. 2)
Two accumulators track cumulative positive and negative log returns. When either exceeds threshold h = 1.5× daily vol, an event fires and both reset.

s⁺ = max(0, s⁺ + rₜ)
s⁻ = min(0, s⁻ + rₜ)
Fire when s⁺ ≥ h or s⁻ ≤ −h

Reduces ~4,200 daily bars to ~1,000 informative events by filtering out low-volatility noise.
Triple Barrier Labeling (AFML Ch. 3)
Each CUSUM event gets three barriers:

▲ Upper: p₀ × (1 + 1.5 × σ) — profit-taking
▼ Lower: p₀ × (1 − 1.5 × σ) — stop-loss
▶ Vertical: t₀ + 10 days — time expiry

Label = whichever barrier is touched first → Up (+1) or Down (−1).

CPCV
Combinatorial Purged Cross-Validation
AFML Ch. 12 — generates multiple backtest paths from a single dataset for PBO estimation.
Groups (N)6 contiguous time blocks
Test groups (k)2 per split
SplitsC(6,2) = 15
Backtest pathsφ(6,2) = 5
Embargo1% of T after each test boundary
Purging & Embargo
Purging: removes training samples whose TBL labels [t₀, t₁] overlap any test group.
Embargo: removes a buffer after each test boundary to guard against serial correlation.
Why CPCV over Walk-Forward?
Walk-forward produces 1 backtest path → no distribution of Sharpe → cannot compute PBO or DSR.

CPCV produces 5 independent paths → Sharpe distribution → Probability of Backtest Overfitting + Deflated Sharpe Ratio.

López de Prado (2018): "A strategy that survives only one backtest path may be a statistical artifact."
CPCV
Per-Fold Preprocessing
Every transformation is fitted on training data only. This is the leakage-critical zone.
① Fractional Differentiation
Makes non-stationary features stationary while preserving memory (AFML Ch. 5).

Sweeps d from 0 → 1 (step 0.05), picks minimum d* where ADF p-value < 0.05.

Applied to: ATR only
Typical d*: 0.15–0.45
② Robust Scaling
Centers by median, scales by IQR. Robust to BTC's fat-tailed distributions.

Fitted on training fold, applied to both train and test.

All 55 features scaled.
③ Multi-Model MDA
Permutation importance with RF + Logistic Regression. Average MDA across both models avoids tree-bias.

Purged inner 3-fold CV within each training set. Keep top 40% of features.

~22 features selected per fold
CPCV
Nested Hyperparameter Tuning
Runs independently inside each of the 15 CPCV splits, using only the 4 training groups.
Inner Purged 3-Fold CV
The 4 training groups are split into 3 contiguous time blocks. For each fold, one block is validation, the rest are training, with 10 observations purged around boundaries.

TRAIN
Optuna TPE + Median Pruner
TPE models good vs. bad parameter regions, concentrating exploration where it matters.

Median Pruner kills trials that underperform the median after each inner fold.

20–30 trials per model. Search spaces capped to prevent overfitting (XGB depth ≤ 6, LSTM hidden ≤ 64, KAN width ≤ 12).
Per-Split Optimal Params
Each split gets its own optimal parameters, correctly simulating dynamic adaptation to changing market regimes.

This nested architecture ensures DSR and PBO remain valid. Tuning on all data → PBO is meaningless.

Conclusions
Key Findings
Methodological Contributions
1. First application of KANs to BTC direction prediction within a rigorous AFML pipeline.
2. Nested per-split tuning (Optuna TPE + Purged K-Fold) preserves DSR/PBO validity.
3. PBO = 0.00 — model selection is robust, not an artifact of backtest overfitting.
4. DSR = 0 for all models — positive Sharpes may still be statistical artifacts under multiple testing correction.
KAN-Specific Findings
1. KAN ranks 4th by median Sharpe (1.22), competitive with RF (1.76) and XGBoost (1.53).
2. KAN's AUC (0.539) is statistically indistinguishable from RF and XGBoost (DeLong test).
3. Symbolic extraction achieved ~90% symbolification rate with 54.8% post-symbolic accuracy.
4. Only macro/crypto features survived — no technical indicator was retained by the KAN formula.
Market Efficiency Implications
All models cluster near 50% accuracy with AUCs around 0.51–0.54. Even the best model (RF with median Sharpe 1.76) has DSR = 0.63, below the 0.95 threshold needed to reject the null hypothesis that the Sharpe is zero. BTC daily returns appear to be efficiently priced, consistent with the weak-form EMH.
Negative Results as Contributions
DSR = 0 and PBO = 0.00 are honest, defensible findings within a rigorous framework. Most crypto-ML papers report inflated metrics from naive pipelines (fixed-horizon labels, no purging, standard CV). This thesis demonstrates that methodological rigor reduces apparent predictability to near-chance levels.
