\section*{Abstract, Keywords, and \gls{jel} Codes}

This dissertation evaluates whether Kolmogorov-Arnold Networks can predict Bitcoin price direction and extract interpretable symbolic formulas, benchmarked against five models within López de Prado's Advances in Financial Machine Learning framework. Using Combinatorial Purged Cross-Validation with the Deflated Sharpe Ratio and Probability of Backtest Overfitting, the study finds that no model achieves statistically significant predictive performance, consistent with market efficiency. The core contribution is KAN symbolic expression extraction, deriving closed-form decision functions from the trained network.

\vspace{1em}

\textsc{Keywords}: Bitcoin; Kolmogorov-Arnold Networks; Symbolic Extraction; Triple Barrier Labelling; Combinatorial Purged Cross-Validation; Financial Machine Learning.

\vspace{1em}

\textsc{\gls{jel} Codes}: C45; C53; C58; G11; G17.

\subsection{Statistical Test Formulae}\label{app:math}
\setlength{\abovedisplayskip}{4pt}
\setlength{\belowdisplayskip}{4pt}

\begin{itemize}\itemsep=3pt
\item \textbf{Fractional-difference weight recursion.}\label{app:ffd_weights} For fractional difference of order $d$: $\omega_0 = 1$,\newline $\omega_k = -\omega_{k-1} \cdot (d - k + 1)/k$. Truncated at the first $k$ with $|\omega_k| < 10^{-4}$, or at $k = 200$. \hyperref[ref:ffd_weights_call]{$\hookleftarrow$}

\item \textbf{Deflated Sharpe Ratio.}\label{app:dsr_formula} Define
\[
E[\max \text{SR}] = \sqrt{2 \ln n}\!\left(1 - \frac{\gamma}{2 \ln n}\right) + \frac{\gamma}{2\sqrt{2 \ln n}}, \qquad
\sigma_{\text{SR}} = \sqrt{\frac{1 - \text{skew} \cdot \text{SR} + \tfrac{\text{kurt} + 2}{4} \cdot \text{SR}^2}{n_{\text{obs}} - 1}}.
\]
Then $\text{DSR} = \Phi\!\left((\text{SR}_{\text{obs}} - E[\max\text{SR}])/\sigma_{\text{SR}}\right)$, with $n$ the number of candidate strategies and $\gamma$ the Euler-Mascheroni constant \citep[Chapter 11]{lopez_de_prado_2018}. \hyperref[ref:dsr_formula_call]{$\hookleftarrow$}

\item \textbf{DeLong pairwise AUC test.}\label{app:delong_formula}
\[
z = \frac{\text{AUC}_a - \text{AUC}_b}{\sqrt{\text{Var}(\text{AUC}_a) + \text{Var}(\text{AUC}_b) - 2 \, \text{Cov}(\text{AUC}_a, \text{AUC}_b)}},
\]
with $\text{Var}$ and $\text{Cov}$ from the structural-component method on pooled predicted probabilities. Two-sided $p$-value from the standard normal CDF \citep{delong_1988}. \hyperref[ref:delong_formula_call]{$\hookleftarrow$}
\end{itemize}

\subsection{Symbolic-Extraction Pipeline Specification}\label{app:symbolic_details}

The pipeline runs on split 27. The stored $d^{\ast}$ and RobustScaler (Section 3.6) are applied to the ATR series and training-fold features, dimensionality is reduced to the top three MDA-selected features, and the data are split chronologically 80/20 into training (540) and validation (135 events), with tanh normalisation $z = \tanh((x - \mu) / (\sigma + 10^{-8}))$ fitted on the training portion. Default architecture is hidden width 5, grid size 5, spline order 3, falling back to hidden width 3 and grid size 3 via the samples-per-parameter envelope of Section 3.11 (Table~\ref{tab:pykan_pipeline} details the four steps; Section 4.6 reports the realised split-27 architecture).

\subsection{Closed-Form Decision Function}\label{app:symbolic}

The closed-form decision function produced by the four-step symbolic-extraction pipeline of Section 3.11 is given in Equation~\ref{eq:decision_function}, with coefficients reported as rationals from symbolic-algebra rational simplification at tolerance $10^{-3}$.

{\footnotesize
\begin{equation}
\label{eq:decision_function}
\begin{split}
\text{decision}(x) ={}
& \tfrac{3}{283}\!\left(\!-\tfrac{284\,\text{ETH/BTC}}{505} - \tfrac{1}{1000}\!\left(\!-\tfrac{1766\,\text{LogRet}_6}{179} - \tfrac{1529}{843}\!\right)^{\!4} \right. \\
& \quad \left. - \tfrac{434}{663}\tanh\!\left(\tfrac{3217\,\text{NatGas}_{30}}{944} + \tfrac{2141}{935}\right) + \tfrac{4511}{913}\right)^{\!2} \\
& - \tfrac{351}{877}\sin\!\bigl(A_2(x)\bigr) + \tfrac{197}{828}\cos\!\bigl(A_3(x)\bigr) + \tfrac{455}{932}\tanh\!\bigl(A_4(x)\bigr) + \tfrac{11}{19}
\end{split}
\end{equation}
}

The inner arguments $A_2(x)$, $A_3(x)$, $A_4(x)$ are themselves multi-feature compositions of the three surviving features under the six surviving primitives ($\sin$, $\cos$, $\tanh$, $x^2$, $x^3$, $x^4$). The implied upward-move probability is $P(\text{Up} \mid x) = \sigma(\text{decision}(x))$ with $\sigma$ the standard logistic.
