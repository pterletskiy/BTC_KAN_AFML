Part 02 · KAN Theoretical Background 4 / 21

Kolmogorov-Arnold Networks · the theoretical foundation

Representation theorem (1957)

Kolmogorov and Arnold proved that any continuous multivariate function on a bounded domain can be written as a finite sum of univariate functions:

Kolmogorov-Arnold f(x1, …, xn) = Σq Φq( Σp φq,p(xp) )
From theorem to network (Liu et al., 2024)
  • A learnable univariate function on every edge, parameterised as a B-spline.
  • Each edge carries a flexible 1D curve, not a single scalar weight.
  • Nodes just sum the activated outputs.
Why KANs for this problem
  • Fewer parameters than MLPs · matters for the 1,168-event sample.
  • Symbolifiable by construction · each 1D edge curve maps to a closed-form primitive.
  • Validated on weak-signal finance · VIX (Wu et al., 2024), KASPER stock prediction.

Phase I · Step 01-02 6 / 21

Data Loading & EWMA Volatility

Data Loading

Source: BTC-USD via yfinance.

Type: daily OHLCV bars.

Date range: November 1, 2014 to May 10, 2026 (about 4,200 daily bars).

Why daily. Daily resolution matches the economic horizon of the macro and on-chain features. Higher frequencies inject microstructure noise that overwhelms signal at this horizon.

Daily Volatility · EWMA

Exponentially-weighted standard deviation of log returns, with span 50:

EWMA volatility σt = √( EWMAspan=50[ rt2 ] )

Why span 50. López de Prado's default for equities is 100; BTC's regime cycle is shorter, so 50 reacts faster to volatility shifts without becoming jumpy.

Two downstream uses of σt:

  1. Sets the CUSUM threshold (next slide).
  2. Sets the profit-take and stop-loss barriers in triple-barrier labeling.

One volatility estimate, two roles. This couples sampling and labeling to the prevailing market regime.

Phase I · Step 03-04 7 / 21

CUSUM Filter & Triple-Barrier Labels

CUSUM Filter
st+ = max(0, st-1+ + rt − E[r])
st− = min(0, st-1− + rt − E[r])
Trigger: |st±| ≥ h · σt,  h = 1.0

Fire an event when accumulated drift exceeds one daily-volatility unit; reset that accumulator and continue. Events fire from 2015-08-08 onward (Ethereum's Frontier launch, the first day with valid eth_btc_ratio data). Yields 1,168 events after the rare-label drop.

Triple-Barrier Labels

From each CUSUM event, watch the next bars until one of three barriers is touched:

  • Take-profit (pt = 1.5 · σt) → label +1
  • Stop-loss (sl = 1.5 · σt) → label −1
  • Vertical barrier (num_days = 10) → sign of the return, or 0 if |return| < 0.02 (the MIN_RETURN floor)

The first barrier touched wins. t1 records the touch time. Residual class-0 events are then dropped via drop_rare_labels(min_pct=0.085), leaving binary {−1, +1} labels.

Phase I · Step 05 8 / 21

Sample Weights · three reasons not every event counts equally

W1

Return magnitude

It does not make sense to treat a day with a +9% return the same as a day with a +1% return. Both might earn the same label +1, but the +9% event carries more information about how strong the signal is.

Component: weight scales with |revent|.

W2

Label uniqueness

When two events overlap in time, the bars between them are double-counted: both labels depend on the same returns. Treating overlapping events as fully independent inflates the effective sample size and lets the model fit noise.

Component: weight scales with how unique each event's labelling window is.

W3

Time decay

Today's BTC market is institutionally dominated, with deeper liquidity and ETF flows. Older periods reflect a smaller, retail-driven market. Recent data is closer to the regime we are forecasting into.

Component: linear time decay, oldest = 40% of newest (time_decay_factor = 0.4).

Final weight: wi = uniquenessi × |ri| × decayi, capped at the 99th percentile and normalized to mean 1. The weights are honored by every model's loss function during training.

Phase II · Step 08 11 / 21

CPCV Split Generation

Configuration
  • N = 8 time-ordered groups, k = 2 test groups per split.
  • Splits = C(8, 2) = 28 · reconstructed paths = 7.
  • Embargo = 11 observations after each test group; train observations whose t1 spans a test group are purged.
  • Per group: ~146 events · average train fold 858, average test fold 292.
Why CPCV beats walk-forward

Walk-forward gives one timeline. One Sharpe number, no variance estimate, no way to tell luck from skill.

CPCV gives seven. Each event appears in multiple test folds across paths, yielding seven path-level Sharpe estimates and enough dispersion for a meaningful Probability of Backtest Overfitting.

Phase II · Step 09-10 12 / 21

Per-Fold Preprocessing · FFD, Robust Scaler, Multi-Model MDA

FFD & Robust Scaler

Fractional Differencing (FFD).

  • Order d ∈ (0, 1) preserves long-run memory while passing ADF.
  • Applied to ATR only · the one non-stationary feature flagged in EDA.
  • d* re-estimated per fold on the training partition.

Robust Scaler.

  • Median + IQR instead of mean + std.
  • Resists BTC fat tails · outliers do not compress the bulk of the distribution.

Both fitted on the train portion of each fold, applied to test.

Multi-Model MDA

Mean Decrease Accuracy.

  • Shuffle one feature, measure F1 drop.
  • Big drop → real signal. No drop → ignored feature.
  • AFML default for unbiased importance (López de Prado).

Why multi-model · a single voter inherits that model's bias.

  • Logistic Regression → linear-combination signal.
  • Random Forest → non-linear-combination signal.

Aggregation.

  • z-score each importance vector, then average.
  • TOP_K_FRAC = 0.20 → top fifth, ~14–15 features per fold.
  • AR Logistic additionally pins its 10 lag columns.

Optuna TPE + MedianPruner

TPE (Tree-structured Parzen Estimator) fits two density models, good past trials and bad, then samples new hyperparameters where the ratio favors the good. MedianPruner kills trials early when their running F1 falls below the median of past trials at the same step.

Tuning is once per split, not per seed. Per tuned model: 28 splits × 40 trials = 1,120 tuning runs, then 28 splits × 5 seeds = 140 final-training runs using the per-split tuned configuration.

Phase II · Step 13 14 / 21

Calibration · raw scores → trustable probabilities

Platt scaling · Platt (1999)

Classical ML

AR Logistic · Logistic Regression · Random Forest · XGBoost
Fits a sigmoid to the 1D log-odds with two free parameters (slope a, intercept b). Can correct both calibration sharpness and directional bias.
Pcal(z) = σ(a · z + b)
Vector scaling · Guo et al. (2017)

Neural networks

LSTM · KAN
Temperature T plus per-class bias b. The bias b0 is pinned to zero to break the softmax overparameterisation, so two free parameters fit: T and b1.
Pcal(z) = softmax( (z + b) / T ),  b0 ≡ 0

S-curve bet sizing · AFML Ch. 10
70 / 15 / 15 partition

Each training fold split chronologically (no shuffling).

  • 70% train — model fit
  • 15% validation — early stopping, best-state tracking
  • 15% calibration — fit Platt or vector scaling
Why vector, not just temperature

Pure temperature scaling preserves the argmax of the logits, so it cannot correct a directional bias. The per-class bias b1 lifts that constraint, fixing both sharpness and direction.

AFML · statistical correction
  • DSR (Ch. 14): Sharpe corrected for trials, skew, kurtosis
  • Survives at DSR ≥ 0.95
  • PBO (Ch. 11): IS-best vs. OOS rank
  • DeLong: pairwise AUC (15 pairs)
Symbolic extraction · Algorithm 1 (Wu et al., 2024)
  1. Train KAN with sparsity penalties (L1 + entropy).
  2. Prune edges below threshold; architecture compresses, e.g. [73, 6, 2] → [3, 3, 2].
  3. Substitute each surviving edge with the best-fitting primitive (sin, cos, tanh, polynomial).
  4. Fine-tune the constants with shapes locked.
  5. Simplify via SymPy.
Output P(Up) = 1 / (1 + exp(−f(x1, x2, x3)))

Part 05 · Limitations & Next Steps 19 / 21

Honest limitations, and the future-work direction each one frames

L1

Daily resolution discards microstructure

Daily bars match the macro feature horizon but skip intraday signal. Next step: hourly extension unlocks order-flow features.

L2

Sample size capped by daily CUSUM events

1,168 events is small by ML standards and drives the wide CIs. Next step: hourly resolution pushes the count past 10,000 and tightens every CI.

L3

No regime-conditional analysis

Full-sample Sharpe averages over BTC's bull, bear, and chop regimes. Next step: regime-conditional results to see if any model survives within a single regime.

L4

Symbolic extraction is fold-specific

Closed-form formula is extracted from fold 27 alone. Next step: per-fold extraction to count which features and primitives recur.

L5

Architectural simplifications for symbolifiability

KAN trained with single hidden layer, grid = 3, top 3 features only. Next step: test whether richer KANs improve trading performance.

L6

Simplified transaction-cost model

Flat 10 bps round-trip cost; no slippage, no market impact, no size dependence. Next step: volatility- and size-aware cost model.
